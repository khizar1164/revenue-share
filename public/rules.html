Point rules

The list you pick from when you record points on the admin page. Editing or deleting a rule doesn't change points already recorded: each entry keeps the wording it was given.

These can be viewed but not changed until the database update is applied.

Use a minus sign for a deduction (−1) and a plain number for a credit (2).
